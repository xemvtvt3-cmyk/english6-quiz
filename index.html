Teacher notes & setup

This version can submit attempts to Supabase when the server environment is configured. The local dashboard remains local to the current browser.

Content plan

  • Vocabulary: school objects and facilities; rooms and furniture; appearance and personality adjectives. Priority is given to A Closer Look 1 and relevant reading vocabulary.
  • Grammar: present simple, present continuous, prepositions of place and possessive ’s.
  • Reading: original short passages on the three unit themes, followed by comprehension questions.
  • Writing: sentence ordering, sentence completion and short constructed responses.

Difficulty distribution

Each skill has 10 questions: 3 understanding, 5 application and 2 advanced application.

Before sharing with students

  1. Review the question bank and answer key.
  2. Online submissions use a server-side Vercel API route. Keep the Supabase service-role key in Vercel Environment Variables only, never in this HTML file.
  3. Teacher class results are stored in Supabase; this browser dashboard and CSV export still show only attempts recorded locally on this device.

Some short reading passages in this prototype are newly written for the quiz rather than copied from third-party websites. External resources are listed in the accompanying notes in the chat.
